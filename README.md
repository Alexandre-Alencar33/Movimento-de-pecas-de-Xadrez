# Simula-o-de-Movimentos-de-Pe-as-de-Xadrez-em-C
Projeto desenvolvido como desafio de programação nível iniciante. O objetivo é praticar o uso das estruturas de repetição (for, while e do-while) simulando os movimentos da Torre, Bispo e Rainha no tabuleiro. O programa exibe no console a direção percorrida a cada casa, reforçando a compreensão de loops e lógica sequencial em C.

 Simulação Avançada de Movimentos de Peças de Xadrez em C

Projeto desenvolvido como desafio de programação nível mestre. O objetivo é aprimorar o uso de recursividade e loops aninhados complexos para simular os movimentos da Torre, Bispo, Rainha e Cavalo no tabuleiro de xadrez.

O programa demonstra:

Torre, Bispo e Rainha: movimentações implementadas com funções recursivas, imprimindo cada direção percorrida.

Bispo: combinação de recursividade e loops aninhados, simulando o movimento diagonal.

Cavalo: movimentação em “L” (duas casas para cima e uma para a direita) usando loops com múltiplas variáveis, break e continue para controle de fluxo.

 Este projeto reforça conceitos avançados de lógica de programação, recursão e controle de laços, aplicados de forma prática na linguagem C.
